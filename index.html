Текущее упражнение

Задача 1 — делегирование событий. В файле script.js найди обработчик клика на taskList. Реализуй удаление задачи при нажатии на кнопку «Удалить».

Условия:
  • Используй один обработчик на ul#taskList.
  • Клик по тексту задачи не должен удалять её.
  • Клик по кнопке или по вложенной в неё иконке должен удалять соответствующий li.
  • Удаление должно работать и для задач, добавленных после загрузки страницы.

Не смотри решение заранее: сначала попробуй написать обработчик самостоятельно. Когда закончишь, сравни с разбором в комментариях к script.js.
